## What is distributed and what is not

- **This repository** is source code. The npm packages are not vendored: `pnpm
  install` fetches them from the npm registry at the versions pinned in
  `pnpm-lock.yaml`.
- **Container images are not published.** `Dockerfile` (the personal harness image)
  and `packages/launcher/Dockerfile` (the launcher) are built by whoever runs the
  harness. The launcher image contains only the launcher bundle (Node built-ins, no
  npm dependencies). The harness image contains the whole installed workspace,
  including DeepSeek Harness and the Claude Agent SDK; whoever builds and
  distributes such an image is responsible for the terms of every component in it,
  in particular for the Claude Agent SDK (below).
- **The browser bundle** (`packages/ui-human-harness`, built by `pnpm build`) includes
  `docx-preview`, `read-excel-file` and their dependencies (among them `jszip`, used
  under its MIT option).

## DeepSeek Harness

The harness is a bundle of plugins for
[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (DSH), consumed as
the `@deepseek-ai/*` npm packages (version pinned in `package.json`) without a fork
and without modification. DSH is licensed under the MIT License; the MIT License
requires its copyright notice and permission notice to accompany all copies or
substantial portions of the software, so the full texts are reproduced in the
generated section below. A few DSH packages carry other licences (MPL-2.0 for the
LibreOffice kit used for office-to-PDF conversion, BSD-3-Clause for a native addon);
they are listed there as well.

## Claude Agent SDK (proprietary)

`@anthropic-ai/claude-agent-sdk` (version pinned in
`packages/llm-claude-code/package.json`, with its per-platform builds
`@anthropic-ai/claude-agent-sdk-<os>-<arch>`) is **not open-source software**. Its
package metadata says `SEE LICENSE IN README.md`; its licence file reads
"© Anthropic PBC. All rights reserved." and makes use subject to Anthropic's legal
agreements (<https://code.claude.com/docs/en/legal-and-compliance>, the
[Commercial Terms of Service](https://www.anthropic.com/legal/commercial-terms)).

- The `claude-code` model provider (`packages/llm-claude-code`) uses it as an npm
  dependency: this repository neither contains nor modifies its code.
- `pnpm install` downloads it from the npm registry; by installing it you accept
  Anthropic's terms.
- Building the harness container image puts the SDK (including its Claude Code
  binary for the image's platform) into the image. Building and distributing such
  an image happens on Anthropic's terms, not under the Apache License 2.0 of this
  repository. The maintainers of this repository do not publish ready-made images.
- Running the assistant needs a Claude subscription token of the person
  (`claude-oauth-token`), used on the terms of that subscription.
